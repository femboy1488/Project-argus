## Argus 0.3.1

**Обновления теперь только с твоего разрешения.**

- Окно «Доступна версия X. Хотите обновить?» с описанием изменений и кнопками **Обновить / Позже / Пропустить эту версию**
- Перед установкой файл проверяется по SHA-256 (`SHA256SUMS.txt`)
- Ноды по USB: «Обновить ноду на <устройство>?» — без ответа нода работает на старой версии
- Ноды по Wi‑Fi: телефон сам показывает запрос на обновление
- Автообновления без вопроса больше нет

### Из 0.3
- Стабильное переподключение после выдёргивания USB, перезапуск движка
- Wi‑Fi-ноды с автопоиском в сети
- Скрипт ноды для Linux / Raspberry Pi

### Как поставить
- ПК: `Argus-Setup.exe` (Windows не подписан — SmartScreen: «Подробнее» → «Выполнить в любом случае»)
- Телефон/планшет: `Argus-Node.apk`
- С 0.3.0 обновиться нужно вручную один раз, дальше Argus предложит обновления сам. Ноды старше 0.3.1 один раз обновить по USB.
